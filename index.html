Git Workflow Discipline

A structured approach to collaboration that keeps the project organized, secure, and easy to follow.

🎯 About This Project

This workflow ensures that every developer on the team follows the same best practices when contributing to the codebase. We use a Feature Branching Workflow to keep the main branch stable and production-ready at all times.

🔀 Branching Strategy

main

The default stable branch — always production-ready.

feature/*

Used for developing new features.

bugfix/*

Used for fixing bugs.

hotfix/*

Used for urgent production fixes.

📝 Commit Message Conventions

feat: A new feature
fix: A bug fix
docs: Documentation changes
style: Formatting changes
refactor: Code refactoring
test: Adding/fixing tests
chore: Build/tooling changes
